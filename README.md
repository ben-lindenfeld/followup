# FollowUp

Hebrew RTL customer, lead and follow-up workspace for small businesses.

The `source` branch contains the editable Next.js application. The `main` branch contains the static site published by GitHub Pages. Build with `npm ci` followed by `npm run build` on the source branch, using the public environment values in `.env.example`.

The November 2026 redesign keeps the existing database, account authentication and RLS rules unchanged. It adds compact work lists, mobile-adapted views, clear feedback, and restrained transitions.
